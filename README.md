# MILANOCASE – Sito web

Sito one-page dell'agenzia immobiliare MILANOCASE (Via Monte Cengio 7, Milano).

Apri `index.html` nel browser, oppure pubblica la cartella su un hosting statico (GitHub Pages, Netlify…).

- `index.html` – struttura e testi delle sezioni
- `css/style.css` – stile
- `js/main.js` – menu, filtri di ricerca, orari "aperto ora"
- `js/listings.js` – **elenco immobili** (gli annunci attuali sono di esempio: sostituirli con quelli reali; si può aggiungere `foto` e `link` a ciascun immobile)
- `assets/` – video di sfondo e foto dell'agenzia
